# Vivek Verma — Portfolio

A responsive single-page portfolio built with **Vite + React** and plain CSS. The design is intentionally restrained and professional, with a focus on senior-level software engineering and freelance enquiries.

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Before publishing

1. Add your actual GitHub and LinkedIn URLs if you want social links in the header/footer.
2. Review project descriptions and ensure they reflect what you are permitted to share publicly.
3. Confirm the location and availability copy is current.
4. Consider adding approved screenshots or case studies for projects you can publicly show.

Project descriptions are based on the supplied resume and avoid invented performance metrics. Contact links use the email and phone number supplied in the resume. Google Fonts are loaded externally with system fallbacks.
